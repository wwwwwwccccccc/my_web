# Spectral Drape

A glowing drape of dots folding in 3D

- Type: React Bits Pro component
- Category: Backgrounds
- Docs: https://pro.reactbits.dev/docs/components/spectral-drape
- Registry item: @reactbits-starter/spectral-drape-tw

## Installation

```bash
npx shadcn@latest add @reactbits-starter/spectral-drape-tw
```

Requires a React Bits Pro license key and the @reactbits-starter registry configured in components.json. Setup guide: https://pro.reactbits.dev/docs/installation
