# 省份照片文件夹

把照片直接复制到对应省份目录即可：

```text
src/assets/province-photos/山东/第一次去青岛.jpg
src/assets/province-photos/四川/成都-01.jpg
```

支持格式：`.jpg`、`.jpeg`、`.png`、`.webp`、`.avif`（也支持大写扩展名）。

## 使用方式

1. 保持开发服务器运行：

   ```powershell
   npm.cmd run dev
   ```

2. 把照片复制进 `src/assets/province-photos/<省份>/`。
3. 浏览器会自动刷新，或手动刷新一次；切到对应省份即可看到照片。
4. 部署前重新构建：

   ```powershell
   npm.cmd run build
   ```

5. `dist/` 里的构建结果才会包含新照片。

## 规则

- 文件名会作为照片标题，例如 `青岛-日落.jpg` 显示为「青岛 日落」。
- 同一个省份内的照片按标题排序。
- 照片名称、说明、日期目前来自文件名/自动生成；如果需要手写说明，可在 `src/data/site.ts` 的 `archiveProvinces` 中维护。
- 这些文件夹里的照片会叠加在示例照片之前，和原来的示例照片共存。
- 从文件夹删除文件，重新刷新后网站里也会消失。
- 不要把照片放到 `dist/images/`，`dist` 是构建产物，会被覆盖。
