# 慢档案 · 参考网站清单

> 站名：**慢档案 / Slow Archive**
> 用途：给"个人生活档案站"定视觉与版式。看的是**版式、信息组织、阅读节奏**，不是内容。
> 访问状态：✓ 当前网络直连可开；△ 海外站/防爬，手动开一般没问题（超时是本机网络问题，不代表站点失效）。

## 三、从主流站抄什么、不抄什么

**抄**：栏宽、字号层级、图注、留白比例、条目信息结构、年度回顾的叙事顺序。

**不抄**：营销大字报、渐变按钮、圆角卡片网格、无限滚动、暗黑霓虹、密集推荐位。
主流产品靠"内容量 + 运营"取胜，个人站要反过来：**少、慢、可读完**。
